# 별빛 섬 — 하늘나무의 노래

빛을 잃은 섬을 천천히 여행하며 흩어진 **별씨앗 12개**를 모아 하늘나무에 다시 꽃을 피우는 3D 힐링 탐험 게임입니다. (예상 플레이 시간 약 30분)

## 실행 방법
ES 모듈을 쓰기 때문에 로컬 웹 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages 등 정적 호스팅에 그대로 올려도 동작합니다. 외부 의존성 없음 (Three.js는 `vendor/`에 포함).

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 드래그 / 휠 | 시점 회전 / 확대 |
| E | 대화 · 상호작용 · 벤치에 앉기 |
| Q | 루미의 힌트 (가까운 빛의 방향) |
| J / Tab | 여행 일지 |

모바일: 왼쪽 화면 드래그로 이동, 오른쪽 드래그로 시점, 화면 버튼으로 점프/상호작용.

## 여행지
- **바람꽃 초원** (남) — 양치기 곰 보리의 길 잃은 양 4마리 찾기
- **달빛 호수** (동) — 징검돌을 건너며 연꽃 등불 4개 밝히기
- **속삭임 숲** (서) — 부엉이 솔의 가락을 버섯을 밟아 연주하기
- **구름 고원** (북) — 떠 있는 돌을 올라 바람의 풍경 울리기

각 땅에는 숨은 별씨앗이 2개씩 더 있습니다. 씨앗을 찾을수록 바랬던 땅에 색과 꽃이 돌아옵니다.
벤치에 앉으면 시간이 빠르게 흐르며 낮과 밤의 변화를 감상할 수 있어요. 진행 상황은 자동 저장됩니다.

## 기술
- Three.js (WebGL), 절차적 지형 · 물 셰이더 · 하늘/별/오로라 셰이더
- 인스턴싱된 풀/꽃/나무와 바람 셰이더, 지역별 채도 복원 효과
- Bloom 후처리, 실시간 그림자, 낮/밤 주기
- WebAudio로 실시간 합성한 배경음악과 효과음 (오디오 파일 없음)
- `?q=low` / `?q=high` 로 그래픽 품질 강제 지정 가능
